# Term

A term is a word or phrase with an optional corresponding definition[^1].

A term is used to explicitly identify a word or phrase for which a definition
has been provided by the author or is expected to be provided by the user[^1].

Do not use a term on interactive elements such as links because doing so could
prevent users of assistive technologies from interacting with those
elements[^1].

See related [definition](./definition.md).

[^1]: https://w3c.github.io/aria/#term
