# Table

A table is a section containing data arranged in rows and columns.

A table is intended for tabular containers which are not interactive. If the
tabular container maintains a selection state, provides its own two-dimensional
navigation, or allows the user to rearrange or otherwise manipulate its contents
or the display thereof, use [grid](./grid.md) or [tree grid](./tree-grid.md)
instead.

See related [grid](./grid.md).
