# Meter

A meter is an element that represents a scalar measurement within a known range,
or a fractional value[^1].

Do not use the meter role to indicate progress;
[progress bar](./progress-bar.md) exists to address that need[^1].

See related [progress bar](./progress-bar.md).

[^1]: https://w3c.github.io/aria/#meter
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/meter/
[^3]: https://www.w3.org/WAI/ARIA/apg/practices/range-related-properties/
