# Status

A status is a type of live region whose content is advisory information for the
user but is not important enough to justify an alert, often but not necessarily
presented as a status bar[^1].

Status is a form of live region. If another part of the page controls what
appears in the status, make the relationship explicit with the `aria-controls`
attribute[^1].

[^1]: https://w3c.github.io/aria/#status
