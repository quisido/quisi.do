# List box

A list box is a widget that allows the user to select one or more items from a
list of choices[^1].

Items within the list are static and, unlike standard HTML select elements, can
contain images. List boxes contain options or groups which in turn contain
options[^1].

See related [combobox](./combobox.md) and [list](./list.md).

[^1]: https://w3c.github.io/aria/#listbox
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/listbox/
