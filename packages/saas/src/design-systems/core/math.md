# Math

Math represents a mathematical expression[^1].

Math is intended to be marked up in an accessible format such as MathML, or with
another type of textual representation such as TeX or LaTeX, which can be
converted to an accessible format by native browser implementations or a
polyfill library[^1].

Use native MathML wherever possible. Use a polyfill library or provide a
fallback image with a text alternative approximation if necessary[^1].

[^1]: https://w3c.github.io/aria/#math
