# Separator

A separator is a divider that separates and distinguishes sections of content or
groups of menu items[^1].

A separator is a static structure that provides only a visible boundary and. It
is not focusable. For example, a static separator can be used to help visually
divide two groups of menu items in a menu or to provide a horizontal rule
between two sections of a page[^1].

[^1]: https://w3c.github.io/aria/#separator
