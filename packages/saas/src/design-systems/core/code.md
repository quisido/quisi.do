# Code

Code content represents a fragment of computer code[^1].

The primary purpose of code is to inform assistive technologies that the content
is computer code and thus might require special presentation, in particular with
respect to synthesized speech. More specifically, screen readers and other tools
which provide text-to-speech presentation of content prefer full punctuation
verbosity to ensure common symbols (e.g. `-`) are spoken[^1].

[^1]: https://w3c.github.io/aria/#code
