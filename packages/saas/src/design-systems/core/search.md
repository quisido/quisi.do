# Search

Search is a landmark region that contains a collection of items and objects
that, as a whole, combine to create a search facility[^1].

A search region can be a mix of host language form controls, scripted controls,
and hyperlinks[^1].

See related [form](./form.md) and [search box](./searhc-box.md).

[^1]: https://w3c.github.io/aria/#search
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/search.html
