# Form

A form is a landmark region that contains a collection of items and objects
that, as a whole, combine to create a form[^1].

A form can contain a mix of host language form controls, scripted controls, and
hyperlinks. If the purpose of a form is to submit search criteria, use a Search
component instead of a generic Form component[^1].

See related [search](./search.md).

A form identifies a region that contains a collection of items and objects that,
as a whole, combine to create a form when no other named landmark is appropriate
(e.g. main or search)[^2].

Use a Search component instead of a form when the form is used for search
functionality[^2].

[^1]: https://w3c.github.io/aria/#form
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/form.html
