# Menu

A menu is a type of widget that offers a list of choices to the user[^1].

A menu is a container, generally rendered as a popup or overlay, for a set of
menu items that can be invoked to perform an action or function. The function is
almost always closely related or directly related to the element that the user
activated to invoke the menu. Activating a menu item both performs the
associated function of the menu item, and results in the automatic dismissal of
the menu[^1].

The menu role is appropriate when a set of menu items is presented in a manner
similar to a popup menu. For instance, a menu could be used to represent a
context menu for its invoking element, or it would be used to render sub-menus
for items of a menubar or another menu popup[^1].

[^1]: https://w3c.github.io/aria/#menu
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/menubar/
