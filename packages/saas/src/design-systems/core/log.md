# Log

A log is a type of live region where new information is added in meaningful
order and old information can disappear[^1].

Examples include chat logs, messaging history, game log, or an error log. In
contrast to other live regions, in this role there is a relationship between the
arrival of new items in the log and the reading order. The log contains a
meaningful sequence and new information is added only to the end of the log, not
at arbitrary points[^1].

[^1]: https://w3c.github.io/aria/#log
