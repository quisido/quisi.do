# Mark

The mark component marks or highlights content for reference or notation
purposes, due to the content's relevance in the enclosing context[^1].

Example uses for mark include:

- Highlighting text in a quotation which is of special interest but is not marked
  in the original source material, comparable to using a highlighter pen to mark
  passages of a print article[^1].
- Indicating portions of the content that are relevant to the user's current
  activity, such as highlighting text matches found by a search feature[^1].

Do not use mark for purely decorative styling such as syntax highlighting[^1].

[^1]: https://w3c.github.io/aria/#mark
