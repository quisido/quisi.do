# Emphasis

Emphasis stresses or emphasizes content. It is not for communicating changes in
typographical presentation that do not impact the meaning of the content. Use
emphasis only if its absence would change the meaning of the content.

Emphasis is not intended to convey importance; for that purpose, the Strong
component is more appropriate.
