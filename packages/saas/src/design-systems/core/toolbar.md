# Toolbar

A toolbar is a collection of commonly used function buttons or controls
represented in compact visual form[^1].

The toolbar is often a subset of functions found in a menu bar, designed to
reduce user effort in using these functions[^1].

[^1]: https://w3c.github.io/aria/#toolbar
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/
