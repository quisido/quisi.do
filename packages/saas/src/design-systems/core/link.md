# Link

A link is an interactive reference to an internal or external resource that,
when activated, causes the user agent to navigate to that resource[^1].

If pressing the link does not change browser focus or page location, use a
button instead[^1].

See related [button](./button.md).

[^1]: https://w3c.github.io/aria/#link
[^2]: https://www.w3.org/WAI/ARIA/apg/patterns/link/
