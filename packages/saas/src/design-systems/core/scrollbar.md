# Scrollbar

A scrollbar is a graphical object that controls the scrolling of content within
a viewing area, regardless of whether the content is fully displayed within the
viewing area[^1].

A scrollbar represents the current value and range of possible values via the
size of the scrollbar and position of the thumb with respect to the visible
range of the orientation (horizontal or vertical) it controls. Its orientation
represents the orientation of the scrollbar and the scrolling effect on the
viewing area controlled by the scrollbar. It is typically possible to add to or
subtract from the current value by using directional keys such as arrow
keys[^1].

[^1]: https://w3c.github.io/aria/#scrollbar
[^2]: https://www.w3.org/WAI/ARIA/apg/practices/range-related-properties/
