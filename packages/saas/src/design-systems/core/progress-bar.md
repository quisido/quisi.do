# Progress bar

A progress bar is an element that displays the progress status for tasks that
take a long time[^1].

A progress bar indicates that the user's request has been received and the
application is making progress toward completing the requested action[^1].

[^1]: https://w3c.github.io/aria/#progressbar
[^2]: https://www.w3.org/WAI/ARIA/apg/practices/range-related-properties/
