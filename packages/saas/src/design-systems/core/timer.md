# Timer

A timer is a section of content containing a numerical counter which indicates
an amount of elapsed time from a start point, or the time remaining until an end
point[^1].

The text contents of the timer object indicate the current time measurement, and
are updated as that amount changes. The timer value is not necessarily machine
parsable[^1].

Update the text contents at fixed intervals, except when the timer is paused or
reaches an end-point[^1].

[^1]: https://w3c.github.io/aria/#timer
