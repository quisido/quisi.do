- If activating a button opened the dialog, the focus should move inside the
  dialog[^1].
- If activating a button closed the dialog without changing logical context,
  focus should return to the trigger that opened the dialog[^1].

[^1]: https://www.w3.org/WAI/ARIA/apg/patterns/button/

[^2]: https://aria-at.w3.org/report/147736
