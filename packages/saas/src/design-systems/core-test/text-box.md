- If the `multiline` prop is `true`, `aria-multiline` is `true` and the widget
  accepts line breaks within the input[^1].
- When a single-line text box is focused, the `Enter` and `Return` keystrokes
  submit the form[^1].
- When a multiline text box is focused, the `Enter` and `Return` keys insert a
  line break[^1].
- Children of a text box must be non-interactive, entirely presentational
  elements[^1].

[^1]: https://w3c.github.io/aria/#textbox
