- The component exposes a named internal or external resource as a native
  link[^1].
- A link participates in the page `Tab` sequence and activates with `Enter`[^2].
- `Space` does not activate a link as though it were a button[^2].
- Running a click handler does not remove the link's native navigation
  behavior[^1].
