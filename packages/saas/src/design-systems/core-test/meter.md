- Set `aria-valuemin` and `aria-valuemax` to indicate the minimum and maximum
  values for the meter[^1].
- `aria-valuemin` defaults to 0 (zero)[^1].
- `aria-valuemax` defaults to 100[^1].
- `aria-valuenow` must not fall below or exceed the computed values of
  `aria-valuemin` and `aria-valuemax`, respectively[^1].

[^1]: https://w3c.github.io/aria/#meter
