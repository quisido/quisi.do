- A figure must be referenced by other text[^1].
- A figure should be renderable at a different location than its reference[^1].
- It should have a caption that includes its name, description text, or
  both[^1].
- When the caption contains the description, use `aria-details`[^1].
- It should support `aria-label` and `aria-labelledby`[^1].

[^1]: https://w3c.github.io/aria/#figure
