- The component exposes a named search-criteria input through the `searchbox`
  role[^1].
- Editing the input reports its displayed value, and controlled value changes
  remain observable[^1].
- Disabled, read-only, and required states are programmatically exposed when
  applicable[^1].
- A search box can serve as the criteria field inside a `search` landmark[^1].

[^1]: https://w3c.github.io/aria/#searchbox
