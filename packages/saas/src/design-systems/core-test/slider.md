- Set the `aria-valuemin` and `aria-valuemax` attributes[^1].
- `aria-valuemin` defaults to 0 (zero)[^1].
- `aria-valuemax` defaults to 100[^1].
- Set the `aria-valuenow` attribute[^1].
- Sliders have an implicit `aria-orientation` value of `'horizontal'`[^1].

[^1]: https://w3c.github.io/aria/#slider
[^2]: https://aria-at.w3.org/report/163642
[^3]: https://aria-at.w3.org/report/163650
